## What is already available and must not be requested again

- Course discussion reads/writes and attachment operations exist. B03 asks for typed reads and reactions, not for creation of the existing endpoints.
- Student progress exists. B01 is a distinction between assignment completion and lesson playback progress.
- Personal events already support CRUD. The frontend now supplies the required UTC query window and current edit version.
- Parent links exist for Advisor, Counsellor and Tenant Admin. B05 concerns a **parent-specific Advisor messaging directory/thread**, not parent association.
- Published course reports, attendance histories, student study-plan task mutations, Instructor grading, Tenant governance, and Parent views already have separate frontend entry points. Keep those role boundaries.

## Acceptance evidence needed from backend owners

For each supported flow, provide a redacted request/response fixture or a designated Dev account within its intended role, and identify the checked-in contract revision it implements. In particular, a typed generic-read replacement should include a populated response, empty response, error response, pagination boundary and cross-student/tenant denial. Until such evidence exists, frontend fixture success is not an assertion of authenticated Dev success.

## Final-review corrections — 2026-09-03

The earlier B06 assertion that High/Medium/Low lacked a source was incorrect: `highestPriority` already exists. It is implemented without inferring priority from risk status. Avatar `GET /v2/users/{userId}/avatar`, system exam detail/section/media reads, and system administrator/user detail reads now have UI consumers. Observer exam lists retain `attemptStatus`, selected sections and reading/listening/writing summaries from the declared DTO.

Assignment creation previously omitted required `weekId` and `learningType`. The editor now selects an actual course lecture and learning category, submits both, and preserves partial versioned PATCH for locked assignments. These were frontend implementation gaps, not backend dependencies.

The export contains icons/assets rather than complete frames. Remaining absent contracts above remain explicitly unaccepted. Latest evidence and release-gate status: [final review](final-figma-review-2026-09-03.md).
